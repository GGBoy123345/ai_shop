# AI商城后端架构设计文档

## 1. 技术选型

| 技术 | 版本 | 说明 |
|------|------|------|
| Spring Boot | 3.x | 基础框架 |
| Spring Cloud | 2022.x | 微服务框架 |
| Spring Cloud Alibaba | 2022.x | 阿里巴巴微服务组件 |
| Nacos | 2.x | 服务注册与配置中心 |
| Spring Cloud Gateway | - | API网关 |
| OpenFeign | - | 服务间调用 |
| Sentinel | - | 流量控制、熔断降级 |
| Seata | - | 分布式事务 |
| MyBatis-Plus | 3.5.x | ORM框架 |
| MySQL | 8.0+ | 数据库 |
| Redis | 7.x | 缓存 |
| RabbitMQ | 3.x | 消息队列 |
| Elasticsearch | 7.17.9 | 搜索引擎（IK中文分词） |
| MinIO | - | 对象存储 |
| Knife4j | 4.x | API文档 |
| **Python** | 3.10+ | AI服务运行环境 |
| **FastAPI** | 0.100+ | Python异步API框架 |
| **LangChain** | 0.1+ | 大模型应用开发框架 |
| **ChromaDB** | - | 向量数据库（存储商品embedding） |

### 2.2 跨语言架构说明

AI服务采用Java适配层 + Python AI引擎的双层架构：

```
┌─────────────────────────────────────────────────────────────────┐
│                    Java微服务层 (Spring Cloud)                   │
│  gateway-svc / user-svc / product-svc / order-svc               │
└──────────────────────────┬──────────────────────────────────────┘
                           │ Feign调用
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│                 Java AI适配层 (ai-mall-ai)                       │
│  职责: 参数校验、鉴权、统一响应格式、调用Python服务               │
└──────────────────────────┬──────────────────────────────────────┘
                           │ HTTP/REST API (RestTemplate)
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Python AI服务层 (FastAPI)                     │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐          │
│  │ 商品材质分析 │  │  成分功效    │  │  商品对比    │          │
│  │   服务       │  │   查询       │  │   分析       │          │
│  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘          │
│         │                 │                 │                   │
│         ▼                 ▼                 ▼                   │
│  ┌─────────────────────────────────────────────────┐           │
│  │              LangChain RAG Pipeline             │           │
│  └─────────────────────────┬───────────────────────┘           │
│                            │                                    │
│         ┌──────────────────┼──────────────────┐                │
│         ▼                  ▼                  ▼                │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐        │
│  │  ChromaDB   │    │   Redis     │    │  LLM API    │        │
│  │ (知识库)    │    │  (缓存)     │    │ (大模型)    │        │
│  └─────────────┘    └─────────────┘    └─────────────┘        │
└─────────────────────────────────────────────────────────────────┘
```

### 2.3 服务职责

| 服务名 | 端口 | 语言 | 职责 |
|--------|------|------|------|
| gateway-svc | 8087 | Java | API网关，统一入口 |
| user-svc | 8081 | Java | 用户、商家、认证、权限 |
| product-svc | 8082 | Java | 商品、分类、属性、SKU |
| order-svc | 8083 | Java | 订单、购物车、退款、支付 |
| search-svc | 8085 | Java | 商品搜索（ES）、搜索历史、索引同步 |
| file-svc | 8084 | Java | 文件上传、图片处理 |
| notify-svc | 8086 | Java | 短信、邮件、站内信 |
| **ai-mall-ai** | **8087** | **Java** | **AI适配层，参数校验、鉴权、调用Python AI服务** |
| **ai-svc** | **8088** | **Python** | **LangChain + RAG，商品材质/成分知识分析** |

## 4. 核心服务接口设计

### 4.1 用户服务 (user-svc)

#### 认证接口

```
POST   /api/auth/login              # 用户登录
POST   /api/auth/register           # 用户注册
POST   /api/auth/logout             # 退出登录
POST   /api/auth/refresh            # 刷新Token
POST   /api/auth/sms/send           # 发送验证码
```

#### 用户接口

```
GET    /api/user/info                # 获取用户信息
PUT    /api/user/info                # 更新用户信息
PUT    /api/user/password            # 修改密码
```

#### 商家接口

```
POST   /api/merchant/apply           # 商家入驻申请
GET    /api/merchant/info            # 获取商家信息
PUT    /api/merchant/info            # 更新商家信息
GET    /api/merchant/list            # 商家列表（管理后台）
GET    /api/merchant/{id}            # 商家详情
PUT    /api/merchant/{id}/audit      # 商家审核
PUT    /api/merchant/{id}/status     # 商家状态变更
```

#### 地址接口

```
GET    /api/address/list             # 地址列表
POST   /api/address                  # 新增地址
PUT    /api/address/{id}             # 更新地址
DELETE /api/address/{id}             # 删除地址
PUT    /api/address/{id}/default     # 设为默认
```

#### 收藏接口

```
GET    /api/favorite/list            # 收藏列表
POST   /api/favorite/{productId}     # 添加收藏
DELETE /api/favorite/{productId}     # 取消收藏
```

## 9. AI知识分析服务设计

### 9.1 功能说明

AI服务采用**Java适配层 + Python AI引擎**的双层架构，基于**RAG（检索增强生成）**模式，为用户提供商品材质/成分的专业知识分析。

**架构分层：**
- **ai-mall-ai (Java, 8087)**：适配层，负责参数校验、鉴权、统一响应格式，通过HTTP调用Python服务
- **ai-svc (Python, 8088)**：AI引擎，负责LangChain RAG检索、知识库管理、LLM调用

**核心能力：**
- 基于商品的材质、成分、配料等属性，进行专业知识解读
- 结合知识库中的专业数据，生成通俗易懂的分析回答
- 支持服装面料、化妆品成分、食品配料等多品类

**典型场景：**
```
用户：这件衣服的面料怎么样？
AI：这件衣服采用95%棉+5%氨纶面料。纯棉含量高达95%，具有良好的透气性和吸汗性，
    非常适合夏季穿着。添加5%氨纶增加了弹性，穿着更舒适，活动更自如。
    建议洗涤时水温不超过30度，避免缩水。
```
