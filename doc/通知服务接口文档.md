# 通知服务接口文档

> **服务名称**：通知服务（notification-service）
> **基础路径**：`/api`（外部接口）、`/internal`（内部接口）
> **协议**：HTTP/HTTPS
> **数据格式**：JSON

---

## 统一响应格式

所有接口均返回以下统一格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 业务状态码，200 表示成功，其他为错误码 |
| message | String | 提示信息 |
| data | Object | 业务数据，具体结构见各接口说明 |

---

## 统一错误码

| 错误码 | 说明 |
|--------|------|
| 80001 | 参数错误 |
| 80002 | 通知不存在 |
| 80003 | 无权操作该通知 |
| 80004 | 短信发送失败 |
| 80005 | 邮件发送失败 |
| 80006 | 短信模板不存在 |
| 80007 | 邮件模板不存在 |
| 80008 | 批量发送数量超限 |
| 80009 | 用户不存在 |
| 80010 | 消息内容为空 |

---

## 一、站内信模块

> 以下接口均需登录，请求头需携带 Token。

### 1. 获取站内信列表

分页查询当前登录用户的站内信列表，支持按消息类型和已读状态筛选。

**请求方式与URL**

`GET /api/notifications`

**请求头**

| 参数名 | 是否必填 | 说明 |
|--------|----------|------|
| Authorization | 是 | Bearer {token} |
| Content-Type | 是 | application/json |

**请求参数（Query）**

| 参数名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| page | Integer | 否 | 页码，默认 1 |
| size | Integer | 否 | 每页数量，默认 10 |
| type | String | 否 | 消息类型筛选：system（系统通知）、order（订单消息）、promotion（促销消息），不传则查询全部 |
| isRead | Boolean | 否 | 已读状态筛选：true 仅已读、false 仅未读，不传则查询全部 |

**响应示例**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [
      {
        "id": 1,
        "title": "订单发货通知",
        "content": "您的订单 SN20260528001 已发货，快递单号：SF1234567890",
        "type": "order",
        "isRead": false,
        "createdAt": "2026-05-28 10:30:00"
      },
      {
        "id": 2,
        "title": "系统维护通知",
        "content": "系统将于 2026-05-29 02:00-06:00 进行维护升级",
        "type": "system",
        "isRead": true,
        "createdAt": "2026-05-27 18:00:00"
      }
    ],
    "total": 25,
    "page": 1,
    "size": 10
  }
}
```

**错误码**

| 错误码 | 说明 |
|--------|------|
| 80001 | 参数错误（page/size 为负数或 type 值不合法） |

## 一、短信模块

> **注意：** 短信和邮件发送当前为 Mock 实现，仅记录日志到 sms_log 表，不实际发送。

---

### 6. 发送短信

向单个手机号发送基于模板的短信。

**请求方式与URL**

`POST /internal/sms/send`

**请求头**

| 参数名 | 是否必填 | 说明 |
|--------|----------|------|
| Content-Type | 是 | application/json |
| X-Service-Key | 是 | 服务间调用密钥 |

**请求参数（Body）**

| 参数名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| phone | String | 是 | 手机号，11 位数字 |
| templateCode | String | 是 | 短信模板编码，如 SMS_VERIFY_CODE、SMS_ORDER_SHIP |
| params | Map<String, String> | 否 | 模板参数键值对，如 {"code":"123456","expire":"5"} |

**响应示例**

```json
{
  "code": 200,
  "message": "短信发送成功",
  "data": {
    "messageId": "MSG20260528103000001",
    "phone": "13800001111",
    "status": "SENT"
  }
}
```

**错误码**

| 错误码 | 说明 |
|--------|------|
| 80001 | 参数错误（手机号格式不正确、模板编码为空） |
| 80004 | 短信发送失败（运营商返回异常） |
| 80006 | 短信模板不存在 |

---

### 7. 批量发送短信

向多个手机号批量发送基于模板的短信。

**请求方式与URL**

`POST /internal/sms/send/batch`

**请求头**

| 参数名 | 是否必填 | 说明 |
|--------|----------|------|
| Content-Type | 是 | application/json |
| X-Service-Key | 是 | 服务间调用密钥 |

**请求参数（Body）**

| 参数名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| phones | List\<String\> | 是 | 手机号数组，单次最多 100 个 |
| templateCode | String | 是 | 短信模板编码 |
| params | Map<String, String> | 否 | 模板参数键值对 |

**响应示例**

```json
{
  "code": 200,
  "message": "批量短信已提交",
  "data": {
    "totalCount": 3,
    "successCount": 3,
    "failCount": 0,
    "results": [
      { "phone": "13800001111", "messageId": "MSG20260528103000001", "status": "SENT" },
      { "phone": "13800002222", "messageId": "MSG20260528103000002", "status": "SENT" },
      { "phone": "13800003333", "messageId": "MSG20260528103000003", "status": "SENT" }
    ]
  }
}
```

**错误码**

| 错误码 | 说明 |
|--------|------|
| 80001 | 参数错误（手机号格式不正确、模板编码为空） |
| 80004 | 短信发送失败（运营商返回异常） |
| 80006 | 短信模板不存在 |
| 80008 | 批量发送数量超限（单次超过 100 个） |

# 附录

## A. 消息类型枚举

| 枚举值 | 说明 |
|--------|------|
| system | 系统通知（维护公告、系统升级等） |
| order | 订单消息（发货通知、签收提醒等） |
| promotion | 促销消息（优惠活动、降价提醒等） |

## B. 短信模板编码对照表

| 模板编码 | 说明 | 模板参数 |
|----------|------|----------|
| SMS_VERIFY_CODE | 验证码短信 | code（验证码）、expire（有效期，分钟） |
| SMS_ORDER_SHIP | 订单发货通知 | orderNo（订单号）、expressNo（快递单号） |
| SMS_ORDER_SIGN | 订单签收提醒 | orderNo（订单号） |

## C. 邮件模板编码对照表

| 模板编码 | 说明 | 模板参数 |
|----------|------|----------|
| MAIL_VERIFY_CODE | 邮箱验证码 | code（验证码）、expire（有效期，分钟） |
| MAIL_ORDER_CONFIRM | 订单确认通知 | username（用户名）、orderNo（订单号）、amount（订单金额） |
| MAIL_ORDER_SHIP | 订单发货通知 | username（用户名）、orderNo（订单号）、expressNo（快递单号） |

## D. 服务间调用说明

内部接口（`/internal/**`）通过 Feign 客户端调用，需在请求头中携带服务密钥：

```
X-Service-Key: {service-secret-key}
```

服务密钥在各微服务的配置文件中统一配置，通知服务侧进行校验。密钥校验失败将返回 HTTP 401。
