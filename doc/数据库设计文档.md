# AI商城数据库设计文档

## 1. 项目概述

### 1.1 技术架构

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端-用户端 | Vue3 + JavaScript | 面向C端用户的商城前台 |
| 前端-商家端 | Vue3 + JavaScript | 面向商家的店铺管理后台 |
| 前端-管理后台 | Vue3 + JavaScript | 面向平台运营的管理后台 |
| 后端 | Spring Cloud | 微服务架构 |
| 数据库 | MySQL 8.0+ | 主数据库，字符集utf8mb4 |
| 缓存 | Redis | 热点数据缓存、分布式Session |
| 搜索 | Elasticsearch | 商品搜索 |
| 消息队列 | RabbitMQ/Kafka | 异步消息处理 |

> **注意：** 实际实现采用单库架构（ai_mall），未采用分库策略。搜索服务使用 MySQL LIKE 查询，未集成 Elasticsearch。短信和邮件服务当前为 Mock 实现。

### 1.2 前端三端说明

#### 用户端 (Customer Web App)
面向普通消费者的商城前台，主要功能模块：
- **首页**：轮播图、推荐商品、分类导航、热销商品
- **商品**：商品列表、商品详情、商品搜索、分类筛选
- **购物车**：加入购物车、数量修改、结算
- **订单**：下单、支付、订单列表、订单详情、确认收货、取消订单
- **个人中心**：个人信息、收货地址、订单管理、收藏夹

#### 商家端 (Merchant Admin)
面向商家的店铺管理后台，主要功能模块：
- **商品管理**：发布商品、编辑商品、商品列表、库存管理
- **订单管理**：订单列表、订单详情、发货、退款处理
- **店铺设置**：店铺信息、店铺装修
- **数据统计**：销售统计、商品分析、订单分析

#### 管理后台 (Platform Admin)
面向平台运营人员的管理后台，主要功能模块：
- **用户管理**：用户列表、用户详情、禁用/启用
- **商家管理**：商家审核、商家列表、商家详情
- **商品管理**：商品审核、分类管理、属性模板管理
- **订单管理**：订单列表、退款审核
- **系统管理**：轮播图管理、系统配置、操作日志

### 1.3 数据库概述

本数据库设计支持AI商城的核心功能，包括用户管理、商家管理、商品管理（支持动态属性）、订单管理、系统管理等。采用MySQL 8.0+，字符集为utf8mb4。

## 4. 动态属性设计说明

### 4.1 设计思路

采用**属性模板 + 属性值**的方式实现动态属性：

1. **属性模板 (attribute_template)**: 定义某个分类下有哪些属性，以及属性的类型、是否必填等
2. **属性选项 (attribute_option)**: 对于单选/多选类型的属性，定义可选的值
3. **商品属性值 (product_attribute)**: 存储商品具体的属性值

### 4.2 示例

**场景：商家上传一件衣服**

1. 系统根据分类"女装"找到属性模板：
   - 衣长 (手动输入, 必填)
   - 材质 (单选: 棉/涤纶/丝绸/羊毛, 必填)
   - 颜色 (单选, SKU属性)
   - 尺码 (单选: S/M/L/XL, SKU属性)

2. 商家填写属性值：
   - 衣长: "70cm"
   - 材质: "棉"
   - 颜色: 红色, 黑色
   - 尺码: M, L, XL

3. 系统存储：
   - product_attribute: 存储衣长=70cm, 材质=棉
   - sku: 自动生成SKU组合(红色-M, 红色-L, 红色-XL, 黑色-M, 黑色-L, 黑色-XL)

### 4.3 查询优化

- 常用属性可通过**冗余存储**或**JSON字段**优化查询性能
- 搜索时可使用**全文索引**或**Elasticsearch**辅助

## 6. 注意事项

1. **字符集**: 使用utf8mb4支持emoji和特殊字符
2. **时间字段**: 使用DATETIME类型，精度到秒
3. **金额字段**: 使用DECIMAL(10,2)避免浮点精度问题
4. **逻辑删除**: 使用deleted字段实现软删除
5. **JSON字段**: MySQL 5.7+支持JSON类型，便于存储动态数据
6. **索引优化**: 根据查询频率建立合适的索引
7. **表名规范**: 使用小写下划线命名，order表需要反引号包裹
