# 订单服务接口文档

> **服务名称**：订单服务（order-service）
> **基础路径**：`/api`（外部接口）、`/internal`（内部接口）
> **协议**：HTTP/HTTPS
> **数据格式**：JSON

---

## 统一响应格式

所有接口均返回以下统一格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 业务状态码，200 表示成功，其他为错误码 |
| message | String | 提示信息 |
| data | Object | 业务数据，具体结构见各接口说明 |

---

## 订单状态流转说明

| 状态值 | 状态名称 | 说明 |
|--------|----------|------|
| 0 | 待付款 | 订单创建成功，等待用户付款 |
| 1 | 待发货 | 付款成功，等待商家发货 |
| 2 | 待收货 | 商家已发货，等待用户确认收货 |
| 3 | 已完成 | 用户确认收货，订单完成 |
| 4 | 已取消 | 用户主动取消或超时未付款自动取消 |
| 5 | 已退款 | 退款申请通过，款项已退还 |

### 7. 创建订单

从购物车选中的商品创建订单。系统会校验商品状态、库存、收货地址，并计算商品金额、运费、优惠金额，生成订单及订单项。创建成功后返回订单信息，进入待付款状态。

**业务流程**

1. 校验收货地址是否存在且属于当前用户
2. 校验购物车项是否存在且属于当前用户
3. 校验商品是否上架、SKU是否存在、库存是否充足
4. 若传入优惠券ID，校验优惠券是否可用
5. 计算商品总金额、运费、优惠金额、实付金额
6. 扣减库存，生成订单号，创建订单及订单项
7. 删除已下单的购物车记录
8. 开启延时任务：30分钟未付款自动取消订单

**请求方式与URL**

`POST /api/orders`

**请求头**

| 参数名 | 是否必填 | 说明 |
|--------|----------|------|
| Content-Type | 是 | application/json |
| Authorization | 是 | Bearer {token} |

**请求参数（Body）**

| 参数名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| addressId | Long | 是 | 收货地址ID，需属于当前登录用户 |
| cartIds | Long[] | 是 | 购物车项ID数组，选中的购物车记录 |
| couponId | Long | 否 | 优惠券ID，不传则不使用优惠券 |
| remark | String | 否 | 买家备注，最多200字 |

**请求示例**

  "addressId": 3001,

## 四、支付模块（模拟支付）

> 支付接口需登录，请求头携带 `Authorization: Bearer {token}`。
> 当前未接入真实支付渠道（支付宝/微信），采用模拟支付实现。

### 20. 模拟支付（订单付款）

对待付款订单执行模拟支付操作。直接将订单状态从待付款（status=0）更新为待发货（status=1），模拟支付成功。

**请求方式与URL**

`POST /api/orders/{id}/pay`

**请求头**

| 参数名 | 是否必填 | 说明 |
|--------|----------|------|
| Content-Type | 是 | application/json |
| Authorization | 是 | Bearer {token} |

**路径参数**

| 参数名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| id | Long | 是 | 订单ID |

**请求参数**

无

**响应示例**

```json
{
  "code": 200,
  "message": "支付成功",
  "data": {
    "id": 90001,
    "orderNo": "20260528103000001001",
    "status": 1,
    "statusText": "待发货",
    "payTime": "2026-05-28 10:32:00"
  }
}
```

**错误码**

| 错误码 | 说明 |
|--------|------|
| 40040 | 订单不存在 |
| 40041 | 无权操作该订单 |
| 40042 | 订单状态不允许支付（非待付款状态） |
| 40100 | 未登录或token已过期 |

### 25. 更新订单状态

更新指定订单的状态，供其他微服务调用（如支付服务回调更新状态、退款服务更新订单状态等）。

**请求方式与URL**

`PUT /internal/orders/{id}/status`

**请求头**

| 参数名 | 是否必填 | 说明 |
|--------|----------|------|
| Content-Type | 是 | application/json |

**路径参数**

| 参数名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| id | Long | 是 | 订单ID |

**请求参数（Body）**

| 参数名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| status | Integer | 是 | 目标状态：0-待付款，1-待发货，2-待收货，3-已完成，4-已取消，5-已退款 |
| operatorId | Long | 否 | 操作人ID（用于日志记录） |
| remark | String | 否 | 状态变更备注 |

**请求示例**

```json
{
  "status": 1,
  "operatorId": null,
  "remark": "用户支付成功，自动流转到待发货"
}
```

**响应示例**

```json
{
  "code": 200,
  "message": "状态更新成功",
  "data": {
    "id": 90001,
    "orderNo": "20260528103000001001",
    "previousStatus": 0,
    "currentStatus": 1,
    "updateTime": "2026-05-28 10:32:00"
  }
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 订单ID |
| orderNo | String | 订单号 |
| previousStatus | Integer | 变更前状态 |
| currentStatus | Integer | 变更后状态 |
| updateTime | String | 更新时间 |

**错误码**

| 错误码 | 说明 |
|--------|------|
| 40001 | 参数错误（status不在合法范围内） |
| 40040 | 订单不存在 |
| 40046 | 状态流转不合法（如从待付款直接跳到已完成） |
