# 搜索服务接口文档

> **搜索引擎**：Elasticsearch 7.17.9 + IK 中文分词器
> **数据同步**：启动时全量同步，每 5 分钟定时全量同步（确保删除数据一致性）
> **降级策略**：ES 不可用时自动降级到 MySQL LIKE 查询

> **服务名称**：搜索服务（search-service）
> **基础路径**：`/api`（外部接口）
> **协议**：HTTP/HTTPS
> **数据格式**：JSON

---

## 统一响应格式

所有接口均返回以下统一格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 业务状态码，200 表示成功，其他为错误码 |
| message | String | 提示信息 |
| data | Object | 业务数据，具体结构见各接口说明 |

### 1. 商品搜索

根据关键词、分类、价格区间等条件搜索商品，支持多种排序方式和分页。基于 Elasticsearch 实现，使用 IK 分词器进行中文分词，支持搜索结果高亮。

**请求方式与URL**

`GET /api/search`

**请求头**

| 参数名 | 是否必填 | 说明 |
|--------|----------|------|
| Content-Type | 否 | application/json |
| Authorization | 否 | Bearer {token}，登录后可获取个性化搜索结果 |

**请求参数（Query）**

| 参数名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| keyword | String | 是 | 搜索关键词，支持商品名称、副标题模糊匹配 |
| categoryId | Long | 否 | 分类ID，筛选指定分类下的商品 |
| minPrice | BigDecimal | 否 | 最低价格，大于等于0 |
| maxPrice | BigDecimal | 否 | 最高价格，大于等于0，需大于等于minPrice |
| sort | String | 否 | 排序方式：`default`（默认综合排序）、`price_asc`（价格升序）、`price_desc`（价格降序）、`sales_desc`（销量降序）、`newest`（最新上架）。不传则默认综合排序 |
| page | Integer | 否 | 页码，默认1 |
| size | Integer | 否 | 每页数量，默认10，最大50 |

**请求示例**

```
GET /api/search?keyword=连衣裙&categoryId=5&minPrice=100&maxPrice=500&sort=sales_desc&page=1&size=10
```

**响应示例**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 128,
    "page": 1,
    "size": 10,
    "keyword": "连衣裙",
    "list": [
      {
        "id": 1001,
        "name": "2024新款<em>连衣裙</em> 夏季清凉修身",
        "subtitle": "优质面料，舒适透气",
        "mainImage": "https://cdn.example.com/products/1001/main.jpg",
        "price": 199.00,
        "marketPrice": 399.00,
        "sales": 500,
        "categoryId": 5
      },
      {
        "id": 1002,
        "name": "法式碎花<em>连衣裙</em> 温柔气质",
        "subtitle": "法式浪漫，优雅出行",
        "mainImage": "https://cdn.example.com/products/1002/main.jpg",
        "price": 259.00,
        "marketPrice": 499.00,
        "sales": 320,
        "categoryId": 5
      }
    ]
  }
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| total | Long | 符合条件的商品总数 |
| page | Integer | 当前页码 |
| size | Integer | 每页数量 |
| keyword | String | 当前搜索关键词 |
| list | Array | 商品列表 |
| list[].id | Long | 商品ID |
| list[].name | String | 商品名称（搜索关键词以 `<em>` 标签高亮，前端需渲染为高亮样式） |
| list[].subtitle | String | 商品副标题（同样支持高亮） |
| list[].mainImage | String | 商品主图URL |
| list[].price | BigDecimal | 售价 |
| list[].marketPrice | BigDecimal | 市场价（划线价） |
| list[].sales | Integer | 累计销量 |
| list[].categoryId | Long | 分类ID |

**业务说明**

- 基于 Elasticsearch 搜索，使用 IK 分词器（索引时 ik_max_word，搜索时 ik_smart）
- 关键词匹配 title（权重 boost 2.0）和 subtitle
- 综合排序（default）：有关键词时按相关性评分排序，无关键词时按销量降序
- 价格区间筛选为闭区间 [minPrice, maxPrice]
- 搜索结果高亮使用 `<em>` 标签包裹匹配关键词，前端需自行渲染高亮样式
- ES 不可用时自动降级到 MySQL LIKE 查询

**错误码**

| 错误码 | 说明 |
|--------|------|
| 40001 | 参数错误（keyword为空、价格范围不合法、排序方式无效、分页参数不合法等） |

### 2. 热门搜索关键词

获取当前平台的热门搜索关键词列表，返回前10个热门搜索词。用于搜索页面的热门搜索展示。

**请求方式与URL**

`GET /api/search/hot`

**请求头**

| 参数名 | 是否必填 | 说明 |
|--------|----------|------|
| Content-Type | 否 | application/json |

**请求参数**

无

```json
{

  "message": "success",

      "score": 9856
    },
    {
      "keyword": "T恤",
      "score": 8720
    },
    {
      "keyword": "运动鞋",
      "score": 7500
    },
    {
      "keyword": "手机壳",
      "score": 6890
    },
    {
      "keyword": "蓝牙耳机",
      "score": 6200
    },
    {
      "keyword": "牛仔裤",
      "score": 5800
    },
    {
      "keyword": "防晒霜",
      "score": 5100
    },
    {
      "keyword": "背包",
      "score": 4700
    },
    {
      "keyword": "短裤",
      "score": 4200
    },
    {
      "keyword": "拖鞋",
      "score": 3900
    }
  ]

```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| keyword | String | 热门搜索关键词 |
| score | Integer | 热度分数，基于搜索频次计算，值越大越热门 |

**业务说明**

- 热门搜索词基于用户搜索行为统计，定时更新（建议每小时刷新一次）
- 返回结果按热度分数降序排列，固定返回前10条
- 此接口无需登录，数据为平台级公共数据

**错误码**

| 错误码 | 说明 |
|--------|------|
| 无 | 该接口不返回业务错误，数据为空时返回空数组 |

### 3. 搜索建议

用户在搜索框输入关键词时，实时返回搜索建议列表（自动补全）。基于商品标题进行前缀匹配和分词匹配，返回最多10条建议。

**请求方式与URL**

`GET /api/search/suggest`

**请求头**

| 参数名 | 是否必填 | 说明 |
|--------|----------|------|
| Content-Type | 否 | application/json |

**请求参数（Query）**

| 参数名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| keyword | String | 是 | 用户输入的搜索关键词（前缀），最少1个字符 |

**请求示例**

```
GET /api/search/suggest?keyword=连衣
```

**响应示例**

```json
{
  "code": 200,
  "message": "success",
  "data": [
    "连衣裙",
    "连衣裙女夏",
    "连衣裙长款",
    "连衣裙修身显瘦",
    "连衣裙碎花"
  ]
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| data | Array[String] | 搜索建议列表，为商品标题字符串数组，按搜索热度和匹配度排序 |

**业务说明**

- 建议结果基于搜索历史+商品标题混合策略
- keyword 长度为1-50个字符，超出截断
- 返回结果去重，最多10条
- 前端应在用户输入时发起请求，建议增加防抖（debounce）处理，避免过于频繁调用

**错误码**

| 错误码 | 说明 |
|--------|------|
| 40001 | 参数错误（keyword为空） |

### 4. 搜索历史

获取当前登录用户最近的搜索历史记录，返回最多20条。搜索历史按时间倒序排列，最新搜索的排在最前面。

**请求方式与URL**

`GET /api/search/history`

**请求头**

| 参数名 | 是否必填 | 说明 |
|--------|----------|------|
| Content-Type | 否 | application/json |
| Authorization | 是 | Bearer {token} |

**请求参数**

无

**响应示例**

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 101,
      "keyword": "连衣裙",
      "createTime": "2026-05-28 15:30:00"
    },
    {
      "id": 100,
      "keyword": "运动鞋",
      "createTime": "2026-05-28 14:20:00"
    },
    {
      "id": 99,
      "keyword": "蓝牙耳机",
      "createTime": "2026-05-27 10:15:00"
    },
    {
      "id": 98,
      "keyword": "手机壳",
      "createTime": "2026-05-26 09:00:00"
    }
  ]
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 搜索历史记录ID |
| keyword | String | 搜索关键词 |
| createTime | String | 搜索时间 |

**业务说明**

- 仅登录用户可查看搜索历史
- 搜索历史在用户每次调用商品搜索接口（GET /api/search）时自动记录
- 同一用户搜索相同关键词时，更新该记录的时间（不重复存储）
- 最多保留最近20条记录，超出后自动删除最早的记录

**错误码**

| 错误码 | 说明 |
|--------|------|
| 40101 | 未登录或Token已过期 |

### 5. 清空搜索历史

清空当前登录用户的全部搜索历史记录。操作不可恢复。

**请求方式与URL**

`DELETE /api/search/history`

**请求头**

| 参数名 | 是否必填 | 说明 |
|--------|----------|------|
| Authorization | 是 | Bearer {token} |

**请求参数**

无

**响应示例**

```json
{
  "code": 200,
  "message": "搜索历史已清空",
  "data": null
}
```

**业务说明**

- 仅登录用户可操作
- 清空后不可恢复
- 仅删除当前用户的搜索历史，不影响其他用户

**错误码**

| 错误码 | 说明 |
|--------|------|
| 40101 | 未登录或Token已过期 |

### 6. 手动同步 ES 索引

手动触发全量同步商品数据到 Elasticsearch。用于数据修复或首次部署时的手动同步。

**请求方式与URL**

`POST /api/search/sync`

**请求头**

| 参数名 | 是否必填 | 说明 |
|--------|----------|------|
| Content-Type | 否 | application/json |

**请求参数**

无

**响应示例**

```json
{
  "code": 200,
  "message": "success",
  "data": "同步完成"
}
```

**业务说明**

- 该接口会删除 ES 中的 product 索引并从 MySQL 全量重建
- 同步过程中搜索服务仍可正常使用（使用旧索引直到重建完成）
- 适用场景：首次部署、数据修复、商品数据异常时手动触发
- 正常情况下无需手动调用，服务启动时自动执行全量同步，之后每 5 分钟定时同步

**错误码**

| 错误码 | 说明 |
|--------|------|
| 500 | ES 连接失败或同步异常 |
